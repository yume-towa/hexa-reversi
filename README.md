# 六角形リバーシ

三角形のマスでできた六角形の盤で遊ぶ、オリジナルのリバーシ（オセロ風）ゲームです。
ブラウザだけで動きます。

## あそびかた

`index.html` をブラウザで開くだけで遊べます。インストールやビルドはいりません。

GitHub Pages で公開する場合は、リポジトリの Settings → Pages で公開するブランチを選ぶと、次のような URL で遊べるようになります。

```
https://<ユーザー名>.github.io/<リポジトリ名>/
```

## 盤面

- 一辺が三角形3個分の、大きな正六角形の盤です。
- 三角形のマスは全部で **54マス** あります。
- 中央の6マスに、黒と白の石を3個ずつ交互に置いた状態から始まります。

## ルール

1. 黒が先手です。黒と白が交互に1つずつ石を置きます。
2. 石を置けるのは、相手の石を **1個以上ひっくり返せる** マスだけです。
3. 相手の石は、次の2つの方法でひっくり返せます。
   - **挟む**：オセロと同じように、列にそって相手の石を自分の石で挟みます。
     列は ▲▼ が交互に並ぶ帯で、縦と斜め2方向の **3方向** があります。
   - **2辺で囲む**：石を置いた結果、相手の石の辺のうち **2つ以上** が自分の石と接したら、その石をひっくり返せます。
     盤の外側に面したマスは辺が2つしかないので、2つとも自分の石と接したときにひっくり返ります。
4. ひっくり返るのは、置いた石で直接挟んだ・囲んだ石だけです。ひっくり返った石がさらに別の石を返す「連鎖」はありません。
5. 相手の石に囲まれたマスに自分から置いた場合、置いた石はその場ではひっくり返りません。
6. 置ける場所がないときはパスです。
7. 両方とも置けなくなったらゲーム終了です。石の多いほうが勝ちです。

## 機能

- **CPU対戦**：先手・後手を選べます。強さは「やさしい」「ふつう」「つよい」の3段階です。
  「ふつう」と「つよい」は、終盤になると最後まで手を読みます。
- **ふたりで対戦**：1台の端末で交互に打てます。
- **待った**：自分の番の局面まで、1手ずつ戻せます。
- **置ける場所の表示**：石を置けるマスに小さな点が出ます。
  パソコンでマスにマウスを乗せると、ひっくり返る石が黄色い輪で表示されます。
- **蜂の巣スキン**：タイトル右の蜂を押すと、蜂の巣モチーフの盤面に切り替わります。
  この盤面では、石も立体的な六角形になります。もう一度押すと、普通の盤面に戻ります。

対戦モードとCPUの強さは、ブラウザに保存されます。次に開いたときも同じ設定で始まります。
